# 苍穹耳语无限无垠 — MIXTAPE NO.001

一盘可以真的拿起来玩的 3D 磁带，和一台能用的卡座。
A / B 两个带面、13 首歌（C60），草地纸飞机与草地猫熊贴纸，只此一盘。

## 打开

GitHub Pages 直接访问即可；本地双击 `index.html` 也可以（无需构建产物之外的任何服务）。

## 怎么玩

- 点击卡座：把磁带放入带仓（⏏ 弹出）
- 磁带在仓外时点击磁带：翻面（A ⇄ B）
- 五枚实体按键：◀◀ 倒带 · ▶ 播放 · ▶▶ 快进 · ■ 停止 · ⏏ 弹出
- 键盘：`空格` 播放/暂停 · `R` 倒带 · `T` 快进 · `S` 停止 · `E` 弹出 · `F` 翻面
- 鼠标拖拽旋转视角，滚轮缩放，双击回默认机位
- 播放中顺序走到一首歌时，右下角会浮出一行浅浅的小字，告诉你这是哪一首

## 真实磁带的物理

- 带卷半径按磁带面积守恒实时变化（r = √(A/π + r₀²)），轮速 ω = v/r 随半径改变
- 倒带 / 快进是纯机械走带：音乐停、马达与带床声继续、卷轴快转，走速恒定
- 翻面位置按真实磁带镜像映射：A、B 面共用同一条磁带的上下两半磁迹，
  翻面后 B 面落点 = B 时长 × (1 − A 面已播比例)。A 面播完翻面，B 恰好从头开始
- 带尾自动倒回带头并停止（自动回零）
- 每首歌在磁带上的真实分界由静音检测实测，点播与报歌名和走带位置一致
